# تست‌های پارچه‌بان

این تست‌ها قبل از هر تغییری در کد اجرا می‌شوند تا مطمئن شوید چیزی نشکسته است.

## نصب یک‌باره

داخل پوشه `tests`:

```bash
cd tests
npm install
```

اگر می‌خواهید تست‌های مرورگری هم اجرا شوند، مرورگر را هم نصب کنید:

```bash
npx playwright install chromium
```

## اجرا

**تست‌های منطقی** (سریع، بدون نیاز به مرورگر یا سرور):

```bash
node tests/run-all.js
```

**همه تست‌ها** (شامل مرورگر). اول در یک ترمینال دیگر برنامه را بالا بیاورید:

```bash
python3 -m http.server 8000
```

سپس:

```bash
node tests/run-all.js --all
```

پورت دیگر: `PB_PORT=8080 node tests/run-all.js --all`

## هر فایل چه چیزی را تست می‌کند

| فایل | موضوع | نوع |
|---|---|---|
| `full.js` | جامع‌ترین تست منطق — محاسبات، اعتبارسنجی، امنیت | منطقی |
| `oversell.js` | جلوگیری از فروش بیشتر از موجودی | منطقی |
| `run.js` | مانده اشخاص، دفتر معین، صفحه‌بندی | منطقی |
| `routes.js` | باز شدن همه مسیرها بدون خطا | منطقی |
| `intl.js` | تبدیل تقویم جلالی ↔ میلادی، ۳۶٬۸۹۰ روز | منطقی |
| `audit.js` | باز شدن هر ۱۶ صفحه و ۷ گزارش در مرورگر واقعی | مرورگری |
| `checkflow.js` | چرخه کامل چک: دریافت، وصول، برگشت، حذف | مرورگری |
| `repexp.js` | خروجی Excel هر ۷ گزارش | مرورگری |
| `offline.js` | بالا آمدن برنامه با قطع کامل اینترنت | مرورگری |

`harness.js` زیرساخت مشترک تست‌های منطقی است؛ مستقیم اجرا نمی‌شود. برنامه را
از روی `index.html` می‌خواند، پس اگر ماژول جدیدی اضافه کنید خودکار دیده می‌شود.

## بررسی کیفیت کد

```bash
cd tests
cat ../js/*.js > /tmp/all.js
./node_modules/.bin/eslint --no-eslintrc -c eslint.json /tmp/all.js
```
